## `> about`

I like understanding how things work under the hood. I started with Arduino projects to see code move something in the physical world, then pushed further into web development and system design.

Most of what I build sits where hardware meets software: sensors, serial communication, firmware, and the interfaces around them. My [portfolio](https://ind-soham.github.io/) works as a public build log, and every project there gets the same write-up: the problem, the solution, and what I learned.

## `> exploring`

- **Hardware + firmware**: designing a custom macropad end to end, from PCB to QMK firmware
- **System architecture**: thinking in components and interfaces instead of single scripts
- **Professional Git workflows**: cleaner commits, branching, and documentation
